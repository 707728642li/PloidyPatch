# Security policy

## Supported versions

Security fixes are provided for the latest `1.x` release. Development branches
and historical research snapshots are not supported production releases.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose data, execute
untrusted content, escape a declared path boundary, or corrupt an annotation.
Email [litaishan@caf.ac.cn](mailto:litaishan@caf.ac.cn) with:

- the affected version and command;
- a minimal reproducer that contains no sensitive biological data;
- the expected and observed behavior; and
- the potential impact.

Receipt will normally be acknowledged within seven days. Please allow time for
verification and a coordinated fix before public disclosure.

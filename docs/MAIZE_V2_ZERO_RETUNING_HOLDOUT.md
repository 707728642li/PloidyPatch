# Maize v0.2 zero-retuning holdout

Date frozen: 2026-08-07  
Status: protocol and source identities frozen before evaluator truth generation.
The protocol-defining commit is `f16b822`; the model-code commit is `43d748b`.

## Purpose

Zea mays B73 NAM-5.0 is the untouched external test of the v0.2 homeolog
topology ranker. Maize is a monocot, is phylogenetically distant from the
soybean and Brassica development species, and retains duplicated genes from a
lineage-specific ancient tetraploidy. Sorghum bicolor and Setaria italica
diverged outside that duplication and provide two declared outgroup
annotations. This tests a different evolutionary regime from the recent
allopolyploid cotton diagnostic.

The model was pooled from soybean and Brassica only and frozen before maize
labels were created. Its SHA-256 is
`e8d0227628bc0688504f1132cca3cd1e418b87a6dbdff39705d35c9c8f933958`.
The model has no calibrated probability, portable threshold, or automatic
repair decision. The sigmoid score is monotonic ranking output only.

## Frozen public inputs

All target and outgroup files are Ensembl Plants release 62 annotations paired
with the matching assembly/protein releases already present under
`/nas_data/NFS/Public_genome_data`. Exact source paths, byte counts, and
SHA-256 values are in `config/maize_v2_source_files.tsv`. Only chromosomes
1-10 are retained for maize and sorghum; Setaria chromosomes I-IX are retained.
Scaffolds and organelles are excluded before any biological inference.

| Role | Species/build | Use |
|---|---|---|
| target | Z. mays B73 NAM-5.0 | perturbed target and blind self-WGD evidence |
| outgroup 1 | S. bicolor NCBIv3 | projection and evaluator pair reconciliation |
| outgroup 2 | S. italica v2.0 | projection and evaluator pair reconciliation |

Candidate-side use of the two references is capped within each algorithm
family. Two references processed by miniprot, for example, remain one miniprot
vote rather than two independent votes.

## Leakage boundary

Before this document and the machine-readable policy are frozen, permitted
maize work is limited to file discovery, checksum and gzip validation, sequence
identifier compatibility, primary-chromosome manifests, and generic code tests.
No complete-annotation homeolog pair, removed gene, hidden CDS chain, label, or
maize performance statistic may enter the candidate process or model.

After freeze, an evaluator-only process may use the complete target annotation
to construct truth and later score already frozen candidates. Candidate
generation may read only the target genome, perturbed annotation, the declared
outgroups, and evidence recomputed from those blind inputs. Truth files and
complete target annotation are never placed under candidate result roots.

Any post-truth change to features, coefficients, references, method voting,
sampler, metric, review budget, or success gate makes maize a development set
and requires another untouched species for a formal claim.

## Evaluator truth construction

The complete target is aligned independently to sorghum and Setaria in a
collinear context. An eligible maize WGD pair must:

1. be supported as the duplicated maize descendants of an outgroup locus by
   both outgroup analyses;
2. be reciprocal-unique after evidence is collapsed by outgroup species;
3. place both maize genes on declared primary chromosomes;
4. have scorable coding transcripts and distinct exact phased CDS chains; and
5. survive ambiguity, tandem-proximity, overlapping-locus, and malformed-CDS
   filters.

The deterministic seed is 20260829. Operable events require one unambiguous
coding transcript per gene because exact hierarchy removal and byte-level
restoration, rather than isoform choice, is the controlled task. The evaluator
samples 800 pairs if at least 800 are eligible. It round-robins over the target
chromosome of the deterministically removed partner; within each chromosome it
round-robins over fixed CDS-segment bins (1, 2-3, 4-6, and 7+) and SHA-256 ranks
within a bin. Exactly one partner per pair is removed by the same predeclared
digest rule used by the perturbation engine, so the other remains available as
a potential blind homeolog. If fewer than 800 pairs pass, all passing pairs are
used and the shortfall is reported; filters are not relaxed.

No-op must recover zero events and the oracle must recover every event exactly.
Applying and reverting any candidate patch must preserve all unrelated
transcript structures and recover the original annotation byte-for-byte.

## Frozen candidate and model workflow

Sorghum and Setaria projections are generated by miniprot, GeMoMa, and LiftOn.
Exact phased-CDS models form the candidate union. Reference replicates are
collapsed within method family before exact 2-of-3 and 3-of-3 tiers are
computed. Blind self-WGD inference supplies an existing partner where possible,
then candidate-partner CDS topology is computed without truth.

The frozen pooled model emits both the original copy-feature baseline and the
topology score on the same candidate rows. The primary comparison therefore
changes only the topology feature family; no maize fit, normalization, or
threshold selection is permitted. Candidates without an accepted existing WGD
partner retain a generic ranking score but are explicitly flagged as topology
unavailable. Automatic approval is always false.

## Endpoints and go/no-go rules

The primary endpoint is exact-CDS average precision of the topology estimator
minus the frozen baseline on the full union. Its interval uses 20,000
chromosome-group bootstrap replicates. The v0.2 portability gate passes only if
the observed delta is positive and the two-sided 95% interval lower bound is
above zero.

Predeclared secondary endpoints are:

- recall and precision within the top 0.5%, 1%, and 2% review budgets;
- topology coverage among hidden-positive candidates, with a 70% minimum gate;
- miniprot, GeMoMa, LiftOn, exact 2-of-3, exact 3-of-3, and technically matched
  SynGAP results;
- exact CDS precision, recall and F1 for method tiers, full-transcript recovery,
  CDS-nucleotide coverage, runtime, peak memory, and abstention rate; and
- complete-annotation negative control, no-op/oracle sentinels, zero collateral
  loss, and reversible patch validation.

The AP gate is the algorithmic claim. Method-tier F1 and review-budget results
are secondary because the v0.2 model intentionally has no cross-species
decision threshold. A failed gate is reported as a failed portability test; it
is not repaired by maize-specific retuning.
